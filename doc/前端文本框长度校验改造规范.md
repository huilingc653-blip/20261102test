# 前端文本框长度校验改造规范（可复用）

> 用途：给新增/修改页面的**文本输入框**按数据库字段长度加前端校验，防止超长内容提交后后端报错。
> 适用范围：bt-saas 项目 layui 体系页面（`*.vm` + 对应 `*.js`）。

---

## 一、标准格式（核心规则）

### 1. 普通文本框 `<input type="text">`

**必填字段**（required + 长度）：
```html
<input type="text" name="xxx" maxlength="N" data-maxlength="N" ... lay-verify="required|strlength"/>
```

**非必填字段**（只校验长度）：
```html
<input type="text" name="xxx" maxlength="N" data-maxlength="N" ... lay-verify="strlength"/>
```

三个属性各自作用：
| 属性 | 作用 |
|---|---|
| `maxlength="N"` | HTML 原生：输入框直接**无法键入**超过 N 个字符 |
| `data-maxlength="N"` | 供 layui 自定义规则 `strlength` 读取，**提交时校验**（汉字算 2 字符、字母数字算 1） |
| `lay-verify="required\|strlength"` | 必填+长度；`lay-verify="strlength"` 仅长度（值为空不报错） |

> N = 数据库字段长度。例：`VARCHAR2(32)` → N=32；`VARCHAR2(150)` → N=150。

### 2. 金额/数字字段（`bt-biz-moneyType` 组件）

**不要**用 `strlength`，金额组件自带 `data-maxlength="20"`，保持原样即可：
```html
<input class="layui-input bt-biz-moneyType" data-maxlength="20" data-name="money" ...>
```

### 3. 多行文本 `<textarea>`

用原生 `maxlength` 即可（参考 securityInfo 的 rmk 备注框）：
```html
<textarea name="rmk" class="layui-textarea" maxlength="200" ...></textarea>
```

## 二、必须同步改的文件（漏改 = 校验不生效）

一个页面往往不止一个文件：

1. **新增页** `addXxx.vm` —— 静态表单里的文本框
2. **修改页** `updateXxx.vm` —— 静态表单里的文本框
3. **新增页 JS** `xxx.add.js` —— 动态加行模板（`addTr()` 等）里生成的文本框
4. **修改页 JS** `xxx.update.js` —— 同上（含 `addImport()` 导入模板）

> JS 里动态生成的 HTML 是字符串拼接，同样要加 `maxlength / data-maxlength / lay-verify`，否则点「+新增行」出来的框没有限制。
> 例（securityInfo）：
> ```js
> trHtml +=' <input type="text" name="levelVOList['+ row +'].productName" ... lay-verify="required|strlength" maxlength="100" data-maxlength="100">';
> ```

## 三、改造步骤（照着做）

1. **拿 DB 表结构**（建表 DDL 或直接告诉我每个字段长度）。
2. **建映射表**：页面 `name` ↔ 表字段 ↔ 长度 ↔ 是否必填。
3. **找页面**：`views/.../xxx/addXxx.vm`、`updateXxx.vm`，以及对应 JS（一般在 `bytter-system-adapter/src/main/webapp/static/modules/.../` 下）。
4. **改静态文本框**：按第一节格式加 `maxlength` + `data-maxlength` + 调整 `lay-verify`。
5. **改 JS 动态模板**：`addTr` / `addImport` / 其它生成行的函数里的同名输入框。
6. **核对**：
   - 必填字段 `lay-verify="required|strlength"`
   - 非必填字段 `lay-verify="strlength"`
   - 金额字段不动（组件自带）
   - 隐藏域（`type="hidden"`）不动

## 四、strlength 规则出处（自查用）

自定义校验规则在 layui 的 form 模块里定义：
```
bytter-system/bytter-system-adapter/src/main/webapp/static/plugins/layui/lay/modules/form.js
bytter-system/bytter-system-adapter/src/main/webapp/static/plugins/oldLayui/lay/modules/form.js
```
逻辑：读 `data-maxlength` / `data-minlength`，汉字按 2 字符算，超长提示「输入的内容长度必须小于 N」。
