看板设计——使用说明

  • 网格布局

网格看板设计采用简单Row+Column布局模式，每行总长度为12，每列对应一个图表，行高度可以调节单位为像素，列高度继承行高。

交叉表默认行高要比普通图表高一些，使用时建议把表格单独放置一行， 如果表格里面数据行过少，再自己调整合适的行高。

网格布局类型的看板设计操作步骤有以下几个：

  • 选择看板类型为网格布局；选择看板的所属分类；填写看板名称。
  • 添加图表和图表列（必须）。点击添加行按钮，执行此操作后，再点击添加列按钮，每列对应一个图表，行高度可以调节单位为像素。添加列后，可以选择设计好的图表来填充列，还可以设置宽度和名称。这一步骤中可以添加多个行以及多个列，这些行和列还可以拖拽排序，自由组合。
  • 添加参数行（可选）。点击添加参数行按钮可以添加参数选项到看板当中，参数选项是看板当中图表所属的数据集中可选的字段，可选择一个或多个字段，所添加的这些字段可应用于过滤数据，查看指定类型的数据列表。
  • 完成上述步骤后，就可点击保存或预览按钮，接着就能查询看板的页面了。
