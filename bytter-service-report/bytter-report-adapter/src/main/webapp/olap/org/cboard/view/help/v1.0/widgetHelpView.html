图表列表区

  • 显示已保存的图表。
  • 左上角功能键可以新建、复制、编辑、删除图表，除新建图表外，其他的操作需要先选中单个图表。
  • 删除也一样只能删除单个图表。
  • 用户在保存列表名称时候按照[Folder]/[SubFolder]/[图表名称]的格式保存之后，会自动更新目录树结构。
  • 列表中的文件加为虚拟目录，实际上并不存在文件夹实体。

模型区

  • 模型区的层级结构需要在数据集设计页面提前定义。否则只能看到原始图表设计的可选列属性。
  • 模型包含4个一级分类节点
    （1）维度列：层级下面的列在支持下钻的图表组件可以进行下钻/上卷操作。
    （2）指标列。
    （3）可选表达式：数据集预先定义；图表设计页面只能使用，不能修改删除；数据集上对指标进行修改会影响图表；数据集中删除已经在图表中使用的指标会导致图表运行失败。
    （4）过滤器：数据集预先定义只能使用，不能修改，不能查看具体内容。

设计区

  • 图表名称格式如：[Folder] / [SubFolder] / [图表名称]。
  • 图表类型切换：不同类型的图表对于输入有不同的限制，鼠标放置在图表类型图标上面有详细提示，点亮状态下为理论可切换状态。
  • 拖拽模型区的元素至设计区输入栏进行图表设计。
  • 图表设计的一些规则
    （1）维度列的元素只能拖拽到列维栏、行维栏和过滤栏。
    （2）指标列的元素只能拖拽到指标栏。
    （3）可选表达式的元素只能拖拽到指标栏。
    （4）过滤器的元素只能拖拽到过滤栏。

在图表设计模块中，用户可以选定某一个数据集，根据其预定义的维度列、指标列、可选表达式、过滤器等模型元素来自行设计一个图表。

图表设计的操作步骤主要有以下几个：

（1）填写图表名称，选择数据集。

（2）拖拽维度列、指标列、可选表达式、过滤器等模型元素进行排列组合，构建图表。

（3）选择图表类型，可在选项中对图表的特性进行设置，然后点击预览。

（4）步骤（2）和步骤（3）可以重复进行，这两个步骤是对图表的设计与完善，当图表满足预期的设想后就可点击保存。

OLAP（联机分析处理）多维分析的数据理论都基于多维数据，多个序列加上相同的index，数据上与之对应最直观的展现为交叉表，交叉表原理同Excel的透视表。

维度过滤/切片排序的操作要点有以下几个：

（1）放置在行维与列维上面的胶囊点击编辑按钮可以进行数据过滤

（2）可以放置维度在过滤栏单纯对数据进行过滤。

（3）为了防止某个维度下面成员数量过大，或者误把连续值如时间戳之类的维度不经处理直接放置在维度框，引起服务端数据源查询压力过大，所以再加载维度成员之前加入了确认操作

（4）过滤比较只支持字符串和数值型比较，由于不同数据库的时间函数处理不一样，但是大多数数据库的时间都能与一个标准的日期字符串进行比较，可能某些数据库会有由于数据类型转换引起的索引失效， 这里没有特殊处理，请数据准备的时候在这块进行一些预处理， 时刻使用预览查询进行调试。

（5）值上的列也可以排序和过滤。
   支持输入值域范围比较。
   从交叉表的形式可以看出，在值排序与行表头排序是冲突的，行排序、各值排序有且仅有一个生效

交叉表（表格）是最为简单的一种图表，在这里可以作为其他图表设计参考的基础模型。

  • 列维在交叉表中表示的是列表头。
  • 行维在交叉表中表示的是行表头。
交叉表与柱线图的对应关系：
  • 交叉表列表头的每一列显示为一条线， 或者一个柱形图序列。
  • 行维则显示为X轴上的节点元素。
